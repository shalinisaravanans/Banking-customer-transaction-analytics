# 📊 Banking Customer and Transaction Analysis

## 📌 Project Overview

This project analyzes banking customer data and transaction information to understand customer behavior, transaction patterns, investments, financial performance, and branch performance.

The project combines SQL, Excel, and Power BI to perform data analysis and create interactive dashboards.

## 🛠️ Tools & Technologies

- SQL
- Microsoft Excel
- Power BI

## 🎯 Project Objectives

- Analyze customer demographics and customer distribution.
- Analyze transaction amounts and transaction patterns.
- Understand investment and financial performance.
- Compare branch-level performance.
- Identify useful business insights from banking data.

## 📊 Dashboard Pages

### 1. Executive Banking Overview

Provides an overall view of customers, transactions, balances, investments, and financial performance.

### 2. Customer & Transaction Analysis

Analyzes customer characteristics and transaction-related patterns.

### 3. Investment & Financial Analysis

Analyzes investment activity and financial performance.

### 4. Branch Performance Analysis

Compares banking performance across different branches and regions.
